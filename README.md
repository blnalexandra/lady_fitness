# Lady Fitness

Aplicație web pentru gestionarea unei săli de fitness dedicate femeilor.

## Descriere
Platforma permite utilizatorilor să își creeze cont, să aleagă un abonament și să se înscrie la clase de fitness. Administratorul poate gestiona clasele, utilizatorii și vizualiza statistici despre site.

## Tehnologii utilizate
- PHP
- MySQL
- HTML / CSS

## Funcționalități
- Autentificare și înregistrare utilizatori
- Înscriere la clase de fitness
- Gestionare abonamente
- Panou de administrare
- Formular de contact
